# 分类
冒险家物品
治疗
所有

# 描述
让变鬼了的朋友回一次魂。能让其他人走得更近。

# 制作材料及解锁
灵魂×10

# 如何获取
无
需沃托克斯技能解锁(wortox_lifebringer_1)

# 备注
沃拓克斯技能：一级回生术
限定沃托克斯技能:一级回生术
效果：双尾心的功能类似于告密的心，将双尾心给予玩家鬼魂即可使其复活，并恢复使用者80理智值。被复活的玩家会受到25%的生命值上限惩罚，可以通过强心针恢复。
如果是学习了“二级回生术”技能的沃拓克斯使用，那么被复活的玩家将不会受到生命值上限惩罚。
角色以双尾心复活后，将有以下属性：
生命值50点。
理智值上限的1/2。
饱食度上限的2/3。
学习了“三级回生术”技能的沃拓克斯可以挤压自己制作的双尾心，将其消耗并立刻释放相当于其剩余保质期/10个灵魂，向上取整。
由此被释放的灵魂被视作由挤压它的玩家所释放，会受到其技能树中“一级灵魂触及”、“一级灵魂堡垒”和“二级灵魂堡垒”的影响。
位于同世界的玩家可以挤压由学习此技能的沃拓克斯制作的双尾心，将自己传送至这个沃拓克斯所在的位置。
保质期10天
