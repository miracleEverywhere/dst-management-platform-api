# 分类
光源
雨具

# 描述
用你脑袋上的灯照亮夜晚。

# 制作材料及解锁
草帽×1、金块×1、萤火虫×1
草帽×1 金块×1 萤火虫×1

# 如何获取
炼金引擎解锁原型
二级科学解锁原型

# 备注
无
头部装备 防水 20%；耐久 7.8 分钟；不可堆叠；不可漂浮；图鉴描述 提供近一天的光照；也有概率自然生成于失败的求生者布景中；与火把相比，矿工帽能提供比更大的照明范围以及更长的照明时间，且耐久消耗速度不受下雨影响；与提灯相比，矿工帽的照明范围不受耐久影响；矿工帽占用的是玩家的头部装备栏来提供照明，让玩家可以空出手部装备栏来做其他工作；建议用荧光果而不是萤火虫为矿工帽添加燃料，因为萤火虫较难再生；猪人、兔人、鱼人、穴居猴也拥有头部装备栏，这意味着他们也可以装备矿工帽来照明。
