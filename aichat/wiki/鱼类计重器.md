# 分类
装饰
钓鱼

# 描述
炫耀你的斩获。

# 制作材料及解锁
冰×4 木板×2 石砖×1

# 如何获取
炼金引擎解锁
二级科学解锁原型

# 备注
无
默认 烧毁；可被锤击4次；图鉴描述 冒险家可以把鱼放进秤盘里，它就会显示出鱼的重量。 一旦装满，只有更重的鱼才能放入秤中，更轻的鱼则会被踢出秤外；鱼类计重器能够永久保存玩家放入其中的活的鱼类，包括淡水鱼、鳗鱼、龙虾、月光龙虾和各种海鱼。和农产品秤一样，放进鱼类计重器的鱼只能由更重的鱼替换下来，或者被拆除时掉落。放上鱼类计重器的鱼会保持放入时的新鲜度，且新鲜度不会因任何原因变化。鱼类计重器能够记录当前鱼的重量以及钓起这条鱼的玩家名字，并且其中的鱼在不是自己钓的重量在此类鱼重量范围的前 20% 的鱼、自己钓的重量在此类鱼重量范围的后 80% 的鱼、自己钓的重量在此类鱼重量范围的前 20% 的鱼，这三种情况下，角色检查鱼类计重器会有不同的评价；尽管制作材料里有冰，但是鱼类计重器依然会被烧毁。
