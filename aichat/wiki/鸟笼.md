# 分类
食物和耕种

# 描述
为你的鸟类朋友提供一个幸福的家。

# 制作材料及解锁
莎草纸×2 金块×6 种子×2

# 如何获取
炼金科技解锁原型

# 备注
可被锤击4次；图鉴描述 笼里可以放一只鸟。 一定要给鸟喂食。 如果给鸟儿喂食水果或蔬菜，鸟儿会把这些作物的种子排泄出来。 如果给鸟儿喂食肉类，它可能会下蛋；鸟笼可以保存玩家捕获的鸟类，所有具有物品形式的鸟都能被放进鸟笼，且一个鸟笼只能放一只鸟。玩家可以随时将原有的鸟类取出并放入新的鸟；蛙腿、怪物肉等猪王不接受的物品可以换成鸟蛋以后再给猪王；鸟笼里的鸟不会因为怪物肉等扣除生命值的食物而死亡；当幸运值小于等于 -0.67 时，将种子给予鸟笼里的鸟（非变异鸟）时必定产出鸟粪；从鸟笼中获取纯粹辉煌的效率远不如切换成威尔逊制作。
