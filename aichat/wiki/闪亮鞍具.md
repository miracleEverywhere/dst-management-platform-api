# 分类
骑乘皮弗娄牛

# 描述
抵消掉完成目标所花费的时间。或许。

# 制作材料及解锁
活木头×2 蜘蛛丝×4 蝴蝶翅膀×68

# 如何获取
二级科学解锁原型

# 备注
耐久 8 次；不可堆叠；不可漂浮；图鉴描述 如果皮弗娄牛愿意的话，可以放在它身上。与普通鞍座相比速度有所提升；这是一个升级版的鞍具，可以装在皮弗娄牛的身上，安装后玩家就能骑上它。只有顺从度高于 50% 的皮弗娄牛才会同意让玩家安装闪亮鞍具，否则它会拒绝安装并且攻击玩家。如果皮弗娄牛因顺从度低于 40% 而主动把自己身上的鞍抖了下来，或皮弗娄牛死亡，闪亮鞍具便会消耗一次耐久度；由于获得蝴蝶翅膀是一个漫长的过程，并且还要考虑新鲜度的因素，因此建议玩家确保有足够的保鲜手段来保存蝴蝶或蝴蝶翅膀或者使用建造护符减少成本。
