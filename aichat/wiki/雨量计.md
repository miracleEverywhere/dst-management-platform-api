# 分类
建筑
夏季物品
雨具

# 描述
观测降雨机率。

# 制作材料及解锁
木板×2 金块×2 绳子×2

# 如何获取
科学科技解锁原型

# 备注
可被锤击4次；图鉴描述 建成后，它将显示当前天气或即将出现的天气。
