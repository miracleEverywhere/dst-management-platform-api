# 分类
武器
航行

# 描述
它能把你的竞争对手从水面轰走。

# 制作材料及解锁
棕榈松果树鳞片×4 绳子×1 木炭×4

# 如何获取
蓝图
其制作配方只能由学习向月亮码头女王进贡香蕉获取的对应稀有蓝图来解锁。

# 备注
无
燃料 燃料类型 火焰燃料 燃料值 3 分钟；不可堆叠；不可漂浮；通过使用鼠标持有大炮套装后移动到地面上或船上按右键建造。也自然生成于月亮码头；如果使用大炮套装在陆地上建造大炮，建造后大炮炮口的朝向总是面对屏幕；如果使用大炮套装在漂浮平台上建造大炮，建造后大炮炮口的朝向是以船中心为起点，向最近边缘延伸的射线方向；如果大炮建造在船上，大炮发射后会提供与发射方向相反的后坐力使船移动；如果在航行中开炮，炮弹的运动轨迹不受船的移动方向和速度影响；火药猴会使用大炮朝目标发射炮弹。如果大炮中存有炮弹，火药猴使用其射击后会消耗其中的炮弹；角色填装后会说出台词表示大炮中是否填入了炮弹，成功填装炮弹后说出的台词和检查装有炮弹的大炮的台词是一样的。
