# 分类
装饰
夏季物品

# 描述
消除火灾蔓延速度。

# 制作材料及解锁
鳞片×1 石砖×1

# 如何获取
炼金引擎解锁
二级科学解锁原型

# 备注
产出×4
燃料 燃料类型 火焰燃料 燃料值 7.5 秒；堆叠上限 20；不可漂浮；图鉴描述 可以放置在泥土地面上以改变地面类型；可通过挖掘龙鳞地板地块来获取；龙鳞地板可以用于大规模生产鳞片，只需要使用拆解魔杖将其分解即可。1 个鳞片能制作 4 个龙鳞地板，而分解每个龙鳞地板都能获得 1 个鳞片；龙鳞地块只阻止引燃。不会改变其它与燃烧/闷烧相关的机制，如火把、火魔杖、岩浆虫、火药的点燃，夏季的野火，或者接触岩浆池的点燃，在龙鳞地块上都会如常生效；产出×4
