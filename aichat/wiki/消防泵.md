# 分类
航行

# 描述
水水水，到处都是水！

# 制作材料及解锁
木板×2 口水鱼×1

# 如何获取
航海科技解锁原型

# 备注
可被锤击3次；图鉴描述 放在船上时，它可以手动操作，从海里汲水喷洒到附近的火堆和冒烟的物品上；消防泵只有建造在船 【 待补充其他漂浮平台？ 】 上才能起作用，灭火范围半径为 7 距离单位 1 距离单位等于 1/4 地块边长，即一般情况下放置墙壁的最小间隔，也是建筑对齐网格的默认间隔。。玩家右键消防泵后不做其他动作可以使它一直工作。相比于雪球发射器。消防泵更能节省船上空间，而且不需要任何燃料；消防泵本身并不防火，但使用消防泵可以为这个消防泵本身灭火；和雪球发射器一样，消防泵难以扑灭位于移动中的船上的火。
