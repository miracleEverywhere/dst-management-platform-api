# 分类
储物方案
钓鱼
航行

# 描述
保持鱼与网捕之日一样新鲜。

# 制作材料及解锁
石砖×1+绳子×3；1级航海科技
石砖×1 绳子×3

# 如何获取
制作
航海科技解锁原型

# 备注
可作业工具工作次数2；图鉴描述放在船上或码头上时，它是一个20栏位的海洋生物容器。容器中的鱼会慢慢恢复新鲜度。
可被锤击2次；图鉴描述 放在船上或码头上时，它是一个20栏位的海洋生物容器。容器中的鱼会慢慢恢复新鲜度；锡鱼罐只能被放置在漂浮平台和码头地块上。它拥有 20 格物品栏，但是只储存海鱼、龙虾和月光龙虾。锡鱼罐中的鱼和龙虾不仅不会死亡，还会以 -0.33 的腐烂倍率来恢复新鲜度，这意味着夏天鱼恢复新鲜度会更快，冬天会更慢，潮湿的鱼恢复新鲜度也会更快，最多 3 天（冬天要更长一点）就能让其中的鱼新鲜度恢复完全；建造在船上的锡鱼罐被摧毁会生成一个大漏洞。
