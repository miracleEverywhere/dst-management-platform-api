# 分类
光源
建筑
烹饪
冬季物品

# 描述
给自己建造一个苍蝇暖炉。

# 制作材料及解锁
鳞片×1、红宝石×2、木炭×10
鳞片×1 红宝石×2 木炭×10

# 如何获取
由学习龙蝇或赃物袋掉落的对应稀有蓝图解锁。
其制作配方只能由学习龙蝇掉落的对应稀有蓝图来解锁。

# 备注
可被锤击6次；图鉴描述 像营火一样提供少量的光和大量的热。它还可以用来销毁物品。
可被锤击6次；图鉴描述 像营火一样提供少量的光和大量的热。它还可以用来销毁物品；其制作配方只能由学习龙蝇掉落的对应稀有蓝图来解锁；在龙鳞火炉周围放置暖石可以快速将其烤热。作为稳定持续热源，龙鳞火炉可以在冬天提供随时可用的过热暖石。容器里的暖石仍可以被龙鳞火炉加热；龙鳞火炉不会引燃周围的东西；可将永远的水果蛋糕放入捆绑包装或礼物包装后再由龙鳞火炉摧毁；龙鳞火炉的温度相当于烧到最旺的火坑火焰。
