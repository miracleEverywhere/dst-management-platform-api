# 分类
冒险家物品
骑乘皮弗娄牛

# 描述
勇士与坐骑，一起战斗吧！

# 制作材料及解锁
金块×4 大理石×3 蓝色羽毛×6

# 如何获取
无
无需解锁

# 备注
耐久6次，薇格弗德技能：战斗鞍具
装备 防御 40% 伤害 5；耐久 6 次；不可堆叠；不可漂浮；图鉴描述 如果皮弗娄牛愿意的话，可以放在它身上。比普通鞍座更慢；这是一个升级版的鞍具，可以装在皮弗娄牛的身上，安装后玩家就能骑上它。只有顺从度高于 50% 的皮弗娄牛才会同意让玩家安装战斗鞍具，否则它会拒绝安装并且攻击玩家。如果皮弗娄牛因顺从度低于 40% 而主动把自己身上的鞍抖了下来，或皮弗娄牛死亡，战斗鞍具便会消耗一次耐久度；技能:战斗鞍具
