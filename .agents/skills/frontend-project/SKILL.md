# 总则
在处理涉及前端逻辑的问题时，你可以查阅前端源码以获取准确信息，但**绝对不能修改前端代码**。

# 前端项目
需要先确认当前系统的类型
前端项目名为dst-management-platform-web，在本机磁盘
如果当前系统是macos，则位于~/WebstormProjects/dst-management-platform-web
如果当前系统是windows，则位于%USERPROFILE%\WebstormProjects\dst-management-platform-web

# 后端代码查阅规范
当遇到前端逻辑相关问题时：
1. **先查阅前端项目源码**
2. **获取准确的操作逻辑**
3. **不得修改任何前端代码**
4. **基于前端实际情况调整后端**
5. **忽略embedFS/dist中的构建产物**
